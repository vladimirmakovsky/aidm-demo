What it is

GreenCart is an online grocery store with home delivery. Customers browse a catalog, add items to a cart, pay online, and choose a delivery slot.

Users
Role	Description
Guest	Browses the catalog and fills a cart. Must register to place an order.
Customer	Registered user. Places orders, earns and spends loyalty points.
Store Manager	Manages catalog, prices, and promotions in the Admin Panel.
Support Agent	Handles refunds and order issues.
Main modules
Catalog: products, categories, search, prices.
Cart: items, quantities, price calculation, discounts.
Checkout: delivery address, delivery slot, payment.
Loyalty: points earned per order, points spent as a discount.
Admin Panel: catalog, pricing, and promotion management.
Notifications: email and push messages about order status.
Platforms
Web application (desktop and mobile browsers)
iOS and Android applications

All platforms use the same backend API. A feature is considered done only when it works on web and on both mobile apps, unless the ticket explicitly limits the scope.

Current priorities (this quarter)
Increase average order value.
Bring back customers who have not ordered for 60+ days.
Reduce the number of support requests about pricing and discounts.
Out of scope for the product
Marketplace model (third-party sellers)
Pickup points (delivery only)
Payments in cash
