# Glossary

Use these terms consistently in tickets, acceptance criteria, and UI texts.

| Term | Definition |
|---|---|
| Cart | The list of items a user intends to buy, before checkout. |
| Cart subtotal | Sum of item prices in the cart, before discounts and delivery fee. |
| Order total | Amount the customer pays: subtotal minus discounts plus delivery fee. |
| Delivery fee | Fixed charge for delivery. Not affected by discounts. |
| Delivery slot | A two-hour time window chosen by the customer for delivery. |
| Discount | Any reduction of the cart subtotal. |
| Promotion | A discount configured by a Store Manager in the Admin Panel. |
| Promo code | A text code entered by the customer to activate a promotion. |
| Loyalty points | Points earned from paid orders that can be spent as a discount. |
| Excluded product | A product that cannot be discounted (see BR-05). |
| Eligible subtotal | Cart subtotal without excluded products. Discounts are calculated from this amount. |
| Guest | A user who is not logged in. |
| Customer | A registered, logged-in user. |
| Store Manager | Internal user who manages catalog, prices, and promotions. |
| Audit log | Record of changes made in the Admin Panel. |
| AC | Acceptance criteria. |
| PO | Product Owner. |
